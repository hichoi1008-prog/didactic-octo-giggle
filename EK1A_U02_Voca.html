2. 엑셀 파일 여는 법

핸드폰일 때:

  • 아이폰: 앱스토어에서 Microsoft Excel 무료 설치 → 파일 앱에서 열기
  • 안드로이드: WPS Office 또는 Microsoft Excel 앱 설치 → 다운로드 폴더에서 열기
  • 카카오톡에서 바로: 파일 꾹 누르고 다른 앱으로 열기 → 드라이브나 시트 선택

컴퓨터일 때:

  • 더블클릭으로 안 열리면, 구글에 접속해서 구글 시트에 드래그해서 넣으면 바로 열려요.
  • 구글 시트 주소: sheets.google.com → 빈 시트 만들기 → 파일 → 가져오기 → 업로드

혹시 구글 시트나 카톡에서 계속 오류가 난다면, 아래 호환성이 더 좋은 파일도 만들어 드렸어요:

  • 엑셀 파일이 또 안 열리면: CSV 파일을 다운로드 받아서 → sheets.google.com 접속 → 빈 시트 → 파일 → 가져오기 → 업로드 하면 바로 보여요.
